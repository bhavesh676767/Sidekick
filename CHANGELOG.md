# Changelog

All notable changes to Sidekick will be tracked here.

## 1.0.0

- Added the MV3 extension runtime.
- Added popup settings for cloud providers and local Ollama.
- Added floating on-page Sidekick notch.
- Added browser task execution loop.
- Added workflow packs for shopping, YouTube, research, writing, productivity, and forms.
- Added local helper bundle for fuzzy matching, readability parsing, memory, OCR, and extraction helpers.
